# Bibliography — TCP/IP

## Referencias principales
1. W. Richard Stevens, Kevin R. Fall — *TCP/IP Illustrated, Volume 1: The Protocols*, 2nd Edition.
2. James F. Kurose, Keith W. Ross — *Computer Networking: A Top-Down Approach*.
3. Andrew S. Tanenbaum, David J. Wetherall — *Computer Networks*.
4. Michael W. Lucas — *Networking for Systems Administrators*.
5. Chris Sanders — *Practical Packet Analysis*.
6. Laura Chappell — *Wireshark Network Analysis*.

## Linux y administración de red
7. Documentación oficial de iproute2: `ip`, `ss`.
8. Linux man-pages: socket(2), tcp(7), udp(7), ip(7), ipv6(7), packet(7).
9. Linux kernel networking documentation.
10. Red Hat Enterprise Linux networking documentation.
11. Fedora networking documentation.

## Packet capture y Wireshark
12. tcpdump/libpcap manual pages and upstream documentation.
13. Wireshark User's Guide.
14. Wireshark Display Filter Reference.
15. tshark manual page.

## Nmap
16. Gordon Lyon — *Nmap Network Scanning*.
17. Nmap Reference Guide y documentación oficial de NSE.

## RFC y estándares esenciales
18. RFC 8200 — Internet Protocol, Version 6 (IPv6) Specification.
19. RFC 9293 — Transmission Control Protocol (TCP).
20. RFC 768 — User Datagram Protocol.
21. RFC 792 — Internet Control Message Protocol.
22. RFC 4443 — ICMPv6.
23. RFC 826 — Address Resolution Protocol.
24. RFC 4861 — Neighbor Discovery for IPv6.
25. RFC 1918 — Address Allocation for Private Internets.
26. RFC 4632 — Classless Inter-domain Routing (CIDR).
27. RFC 1191 — Path MTU Discovery.
28. RFC 8201 — Path MTU Discovery for IPv6.

## Uso recomendado
- Stevens/Fall: referencia profunda de protocolos.
- Kurose/Ross y Tanenbaum/Wetherall: fundamentos y arquitectura.
- Sanders/Chappell: captura y análisis de paquetes.
- Documentación Linux: comportamiento real del stack y CLI.
- RFC: fuente normativa para profundización y resolución de dudas.
- Nmap upstream: comportamiento, opciones y NSE.

La bibliografía debe usarse como apoyo; cuando una RFC haya sido sustituida o actualizada, debe priorizarse la especificación vigente.
