# JavaScript — Bibliography

## Principal

### David Flanagan — *JavaScript: The Definitive Guide, 7th Edition*

Referencia principal para el lenguaje JavaScript, objetos, arrays,
funciones, clases, módulos, asincronía, plataforma web y Node.js. Debe
actuar como columna vertebral conceptual del curso.

## Fundamentos y aprendizaje progresivo

### Eric Freeman, Elisabeth Robson — *Head First JavaScript Programming, Second Edition*

Referencia pedagógica prioritaria para los bloques iniciales. Útil para
introducir sintaxis, valores, funciones, objetos, DOM y razonamiento
práctico antes de entrar en los internals.

## Práctica y resolución de problemas

### Adam D. Scott, Matthew MacDonald et al. — *JavaScript Cookbook: Programming the Web, 3rd Edition*

Referencia práctica para recetas, Web APIs, manipulación de datos,
navegador, red y resolución de problemas reales. Sus ejemplos deben
complementar, no sustituir, la explicación conceptual.

## Concurrencia e internals del runtime

### Thomas Hunter II, Bryan English — *Multithreaded JavaScript: Concurrency Beyond the Event Loop*

Referencia principal para event loop avanzado, workers, worker_threads,
SharedArrayBuffer, Atomics, memoria compartida, concurrencia y
paralelismo.

Especialmente relevante para: - Bloque 23 — Event loop en profundidad. -
Bloque 24 — Concurrencia y paralelismo. - Bloque 43 — Concurrencia
avanzada y memoria compartida. - Bloque 44 — Arquitecturas asíncronas
avanzadas. - Bloque 47 — Runtime, profiling y optimización avanzada.

## Aplicaciones full-stack y multiplataforma

### Adam D. Scott — *JavaScript Everywhere: Building Cross-Platform Applications with GraphQL, React, React Native, and Electron*

Referencia de integración para construir aplicaciones JavaScript en web,
servidor, móvil y escritorio.

Especialmente relevante para: - Bloque 38 — React fundamentals. - Bloque
39 — GraphQL. - Bloque 40 — React Native. - Bloque 41 — Electron. -
Bloque 42 — JavaScript Everywhere. - Bloque 48 — Proyecto final.

## Referencias normativas y documentación oficial

Para semántica exacta y características modernas se debe priorizar
documentación normativa/oficial actualizada:

- ECMAScript Language Specification — ECMA-262.
- TC39 — propuestas y proceso de estandarización.
- MDN Web Docs — JavaScript y Web APIs.
- Node.js Documentation — runtime y APIs de Node.js.
- npm Documentation — paquetes, CLI y package.json.

## Política de uso bibliográfico

Las lecciones deben utilizar referencias exactas solo cuando hayan sido
verificadas. No inventar números de página, capítulos o secciones.

La bibliografía debe combinarse por función:

1.  Head First JavaScript Programming → entrada pedagógica.
2.  JavaScript: The Definitive Guide → lenguaje y referencia central.
3.  JavaScript Cookbook → práctica y APIs.
4.  Multithreaded JavaScript → concurrencia e internals.
5.  JavaScript Everywhere → integración cross-platform.
6.  Especificaciones y documentación oficial → comportamiento normativo
    y características actuales.
