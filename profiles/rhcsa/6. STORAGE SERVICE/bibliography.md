# bibliography.md — FILE / STORAGE SERVICES

## Documentación principal

1. Red Hat Enterprise Linux — documentación de administración de file systems y storage.
2. Red Hat Enterprise Linux — documentación de NFS.
3. Red Hat Enterprise Linux — documentación de Samba.
4. Red Hat Enterprise Linux — documentación de iSCSI y Device Mapper Multipath.
5. Fedora Documentation — administración de sistemas y almacenamiento.
6. `man exports`, `man nfs`, `man nfs.conf`, `man nfsstat`, `man mount.nfs`.
7. `man autofs`, `man auto.master`, `man automount`.
8. `man smb.conf`, `man smbclient`, `man mount.cifs`, `man smbstatus`.
9. `man iscsiadm`, `man iscsid`, `man multipath`, `man multipath.conf`.
10. Samba Project Documentation.
11. Linux Kernel documentation — NFS, SCSI y device mapper cuando corresponda.

## Libros recomendados

- *Using Samba* — documentación/libro de referencia para comprender Samba y SMB.
- *NFS Illustrated* — Brent Callaghan.
- *Storage Networks Explained* — fundamentos de SAN, NAS y almacenamiento en red.
- *Linux Storage* — referencias prácticas de almacenamiento Linux, LVM, device mapper y filesystems.

## Fuentes prácticas

La documentación instalada y las páginas `man` forman parte obligatoria del aprendizaje. En cada bloque se debe contrastar la versión de Fedora/RHEL utilizada, porque nombres de paquetes, defaults, opciones y unidades systemd pueden evolucionar.
