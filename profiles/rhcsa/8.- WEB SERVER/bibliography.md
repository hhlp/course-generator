# Bibliography — Web Servers

## Documentación principal
- Apache HTTP Server Documentation — referencia oficial de `httpd`, módulos, VirtualHost, proxy, TLS, logging y tuning.
- NGINX Documentation — referencia oficial de configuración, server/location, proxy, FastCGI, TLS y upstreams.
- HAProxy Documentation — Configuration Manual, Management Guide y Runtime API.
- Red Hat Enterprise Linux Documentation — administración de servicios web, systemd, SELinux, firewalld y seguridad.
- Fedora Documentation — paquetes y administración del sistema Fedora.
- PHP Manual — PHP-FPM y configuración FastCGI.
- OpenSSL Documentation — herramientas y diagnóstico TLS.
- Let's Encrypt / ACME documentation — emisión y renovación de certificados.
- FreeIPA Documentation — servicios HTTP, principals, keytabs e integración de servicios con identidad central.
- MIT Kerberos Documentation — principals, keytabs, tickets y autenticación Kerberos/SPNEGO.
- OpenLDAP Documentation — LDAP, bind/search, TLS y diagnóstico de integración con directorios.

## Estándares y referencias HTTP/TLS
- RFC 9110 — HTTP Semantics.
- RFC 9112 — HTTP/1.1.
- RFC 9113 — HTTP/2.
- RFC 9114 — HTTP/3.
- RFC 8446 — TLS 1.3.
- RFC 7239 — Forwarded HTTP Extension.

## Libros complementarios
- *Apache: The Definitive Guide* — referencia conceptual e histórica útil para comprender Apache; contrastar directivas con documentación actual.
- *Nginx Cookbook* — recetas prácticas para operación y proxying; contrastar sintaxis/versiones con documentación actual.
- *High Performance Browser Networking* — Ilya Grigorik; fundamentos de TCP/TLS/HTTP y rendimiento web.

## Criterio de uso
La documentación oficial y los RFC tienen prioridad para sintaxis y comportamiento vigente. Los libros se utilizan para explicación, arquitectura, ejercicios y contexto, no como sustituto de la documentación de la versión instalada.
