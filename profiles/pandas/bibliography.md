# Bibliografía — Pandas 3

## Principal
### Daniel Y. Chen — *Pandas for Everyone, Second Edition*
Base pedagógica del learning path. Se utiliza para introducir progresivamente Series, DataFrame, limpieza, transformación, combinación, agrupación y análisis con datasets.

## Patrones y Pandas idiomático
### Matt Harrison — *Effective Pandas: Patterns for Data Manipulation*
Referencia transversal para patrones idiomáticos, vectorización, tipos, method chaining, legibilidad, rendimiento y antipatterns. Sus ideas se introducen durante todo el curso y tienen especial peso en selección, tipos, transformación, GroupBy, joins, categorías, optimización y pipelines.

## Práctica y profundización
### Boris Paskhaver — *Pandas in Action*
Referencia práctica para consolidar Series/DataFrame, selección, transformación, agregación, combinación, reshape y análisis mediante workflows y problemas completos.

## Referencia normativa
### Documentación oficial de pandas 3.x
Autoridad para API y comportamiento vigente, especialmente Copy-on-Write, dtypes modernos, indexación/asignación, I/O, GroupBy, merge/join/concat, reshape, series temporales, rendimiento, deprecaciones y migración.

## Jerarquía de uso
1. La documentación oficial determina el comportamiento de Pandas 3.
2. Chen proporciona la progresión pedagógica principal.
3. Harrison aporta el patrón idiomático y las buenas prácticas.
4. Paskhaver aporta práctica y profundización.

No es obligatorio utilizar los tres libros en cada lección. Las referencias se seleccionan por relevancia. Las referencias exactas a capítulos, secciones o páginas solo se añaden cuando hayan sido verificadas.
