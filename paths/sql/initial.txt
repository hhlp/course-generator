SQL — LEARNING PATH 0 → EXPERTO (PostgreSQL)

  Alcance: aprender SQL como lenguaje de consulta, transformación y
  manipulación de datos. PostgreSQL es la plataforma práctica de
  referencia.

  Fuera de alcance: normalización (1FN, 2FN, 3FN, BCNF…), dependencias
  funcionales, diseño ER, diseño lógico/físico de bases de datos y
  teoría de diseño relacional. Estos temas pertenecen al PATH Relational
  Database Design.

  Las claves primarias y foráneas aparecen únicamente cuando son
  necesarias para comprender consultas, integridad referencial y JOINs.

FRONTERA CON DATABASE DESIGN

Este PATH no enseña normalización, formas normales, dependencias
funcionales, claves candidatas como problema de diseño, diseño ER,
transformación ER→relacional, descomposición, anomalías de diseño,
teoría relacional de C. J. Date ni decisiones sobre almacenar/calcular
atributos derivados. Esos contenidos permanecen en Relational Database
Design.

Aquí PK, FK, restricciones e índices solo aparecen cuando son necesarios
para escribir, comprender, validar u optimizar una consulta SQL.
