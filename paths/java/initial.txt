JAVA — LEARNING PATH 0 → EXPERTO EN PROFUNDIDAD

Objetivo general
Dominar Java moderno desde cero hasta un nivel experto: lenguaje, orientación a objetos, genéricos,
colecciones, programación funcional, Streams, I/O/NIO, networking, reflexión, concurrencia,
multihilo, programación asíncrona, virtual threads, bases de datos con JDBC, persistencia,
JavaFX, testing, build tools, JVM, bytecode, memoria, garbage collection, JIT, rendimiento,
profiling, seguridad, arquitectura, observabilidad, XML, internacionalización, AWT/Swing, FFM y troubleshooting.

El aprendizaje será práctico. Cada bloque debe combinar teoría, ejemplos ejecutables,
laboratorios y, cuando corresponda, análisis interno de la JVM y herramientas CLI.


PLATAFORMA Y RUTA DE ESTUDIO — REVISIÓN 2026-10-19
Base: OpenJDK 25, APIs estables por defecto; preview en laboratorio separado.
Se conservan los IDs de las lecciones originales. Los números identifican contenidos;
las siguientes dependencias determinan cuándo ejecutar las prácticas avanzadas.

- Bloque 0: configurar un build mínimo y JUnit antes del primer proyecto.
- 4.17–4.18: wrappers/boxing antes de generics y Collections; 17 los consolida.
- 8.3: presentación conceptual; uso profundo de EnumSet/EnumMap después del 11.
- Bloque 12, primera pasada: 12.1–12.19, 12.24, 12.32–12.36 con código conocido.
  Retomar 12.20–12.23 tras 15; 12.25 tras 19; 12.26 tras 32; 12.27 tras 29;
  12.28–12.31 tras 41–45. Las comparaciones completas de APIs se hacen tras estudiarlas.
- Laboratorios 11–12: razonar operaciones y contratos; JMH solo tras 45.
- 15: parallel streams se presentan con restricciones y se retoman tras 26.
  Los streams respaldados por recursos se retoman tras 18–19.
- 19: servidor con NIO secuencial/event loop; versión con threads después del 26.
- 20.10: visión conceptual; implementación HTTP async tras 27 y servidor concurrente
  tras 26. WebSocket avanzado se retoma tras dominar asincronía.
- 21: laboratorio de reflexión primero; completar anotaciones después del 22.
- 23–29: estudiar después de 20; retomar VarHandle tras JMM y atomics.
- Introducir testing desde 0; 35 profundiza y consolida la suite acumulada.
- 37–38 profundizan el build mínimo; JavaFX/JPA/tests usan versiones fijadas desde
  su primer laboratorio. El material debe proporcionar pom/build y wrapper completos.
- 54 es la entrega base; la defensa final ocurre después de 55–60 y de integrar
  las extensiones pertinentes. No se exige incorporar FFM sin una necesidad real.

Cada laboratorio declara prerrequisitos, comandos, salida esperada, pruebas y limpieza.
Las pruebas de concurrencia se coordinan explícitamente; sleep no demuestra corrección.
Regex y Big-O requieren únicamente sus fundamentos externos al llegar a su aplicación;
sus teorías generales no se vuelven a desarrollar en este PATH.
