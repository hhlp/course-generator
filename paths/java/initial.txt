JAVA — LEARNING PATH 0 → EXPERTO EN PROFUNDIDAD

Objetivo general
Dominar Java moderno desde cero hasta un nivel experto: lenguaje, orientación a objetos, genéricos,
colecciones, programación funcional, Streams, I/O/NIO, networking, reflexión, concurrencia,
multihilo, programación asíncrona, virtual threads, bases de datos con JDBC, persistencia,
JavaFX, testing, build tools, JVM, bytecode, memoria, garbage collection, JIT, rendimiento,
profiling, seguridad, arquitectura, observabilidad, XML, internacionalización, AWT/Swing, FFM y troubleshooting.

El aprendizaje será práctico. Cada bloque debe combinar teoría, ejemplos ejecutables,
laboratorios y, cuando corresponda, análisis interno de la JVM y herramientas CLI.
