TYPESCRIPT — LEARNING PATH 0 → EXPERTO

Objetivo: dominar TypeScript desde la semántica de JavaScript y ECMAScript hasta su sistema de tipos, Node.js, asincronía, concurrencia, paralelismo, memoria y runtime, diseño type-safe, compilador, AST, TypeChecker, Compiler API, rendimiento y seguridad, comprendiendo tanto el comportamiento en compile time como el código JavaScript resultante en runtime.

Secuencia: el bloque 0 incluye el puente JavaScript necesario para comenzar desde cero. Los identificadores originales se conservan. El bloque 43 desarrolla el proyecto progresivo; la entrega final se realiza en el bloque 46, después de Regex y Big O.
