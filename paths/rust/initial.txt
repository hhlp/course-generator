RUST — LEARNING PATH 0 → EXPERTO

Objetivo general
Dominar Rust desde los fundamentos del lenguaje hasta programación de sistemas, concurrencia,
async, unsafe, FFI, diseño idiomático, rendimiento, internals del compilador y desarrollo
profesional de crates y aplicaciones.

CRITERIOS DIDÁCTICOS
- Enseñar primero el modelo mental y después la sintaxis.
- Ownership, borrowing y lifetimes deben reforzarse durante todo el curso, no estudiarse una sola vez.
- Todo concepto importante debe incluir código compilable y ejercicios.
- Mostrar errores reales del compilador y enseñar a interpretarlos.
- Diferenciar explícitamente safe Rust de unsafe Rust.
- En concurrencia, explicar Send, Sync, atomics y el memory model antes de estructuras lock-free avanzadas.
- En async, explicar Future, Poll, Waker y Pin, no limitarse a usar un runtime.
- Incluir rendimiento sólo con mediciones, benchmarks y profiling.
- Los bloques expertos deben conectar el lenguaje con rustc, MIR, LLVM, ABI, SO y hardware.
- Usar documentación oficial como autoridad primaria para semántica y comportamiento del lenguaje.
- Terminar cada bloque importante con laboratorios y cada nivel con un proyecto integrador.
