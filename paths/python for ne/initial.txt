PRINCIPIO DEL PATH Este PATH NO enseña Python general desde cero. Presupone el PATH general de Python. Python, Regex, Git, redes y protocolos se introducen aquí solo en la medida necesaria para aplicarlos a automatización, configuración, validación, observabilidad y troubleshooting de infraestructura de red. Referencia de partida: Python for Network Automation / Python for Network Engineer (Syed Asif), ampliada a un itinerario profesional y profundo.
