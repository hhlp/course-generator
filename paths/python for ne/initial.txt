PYTHON NETWORK AUTOMATION / NETWORK PROGRAMMABILITY
0 EN AUTOMATIZACIÓN DE REDES → EXPERTO EN PROFUNDIDAD
Especialización: Cisco Routers & Switches

PRINCIPIO DEL PATH
Se presupone Python general; no se reenseña el lenguaje. También se requieren
Linux/terminal, Git y redes: Ethernet, VLAN, IPv4/IPv6, routing y SSH básicos.
OSPF/BGP y switching avanzado se estudian previamente o justo antes de sus labs.
El PATH general de Ansible se requiere al llegar al BLOQUE 28, no para comenzar.
Regex se consume del PATH específico cuando se necesite parsing de texto.
Referencia inicial: Python for Network Automation, de Syed Asif, ampliada
con documentación oficial y prácticas de ingeniería de automatización.

LECTURA Y EVALUACIÓN
Cada entrada N.M es una lección; sus líneas «Alcance» son subtemas, no lecciones.
La profundidad depende de teoría, implementación, fallos y evidencia práctica.
Los checkpoints requieren evidencias reproducibles y criterios PASS/FAIL.
Las configuraciones y scripts se implementan durante las lecciones: estos
cuatro archivos definen el currículo y no contienen un laboratorio ejecutable.
No se presupone una imagen Cisco que soporte todos los protocolos.
