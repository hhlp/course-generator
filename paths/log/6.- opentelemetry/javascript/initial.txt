OPENTELEMETRY CON JAVASCRIPT — DE CERO A EXPERTO

Path independiente de especialización. Node.js principal; navegador y TypeScript como extensiones.
Requiere JavaScript básico y fundamentos de OpenTelemetry; no enseña JavaScript desde cero.
El curso general conserva arquitectura y operación transversal. Este path profundiza en implementación JavaScript.
Este paquete define el currículo; las lecciones generadas deberán aportar código y laboratorios completos.
