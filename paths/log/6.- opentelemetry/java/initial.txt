OPENTELEMETRY CON JAVA — DE CERO A EXPERTO
Especialización independiente del tronco común de OpenTelemetry.
Cero se refiere a instrumentación Java: no sustituye un curso de Java.
Formato: bloque N; lecciones N.1–N.10, sin reinicios ni saltos.
Los contenidos son un PATH y especificaciones de lecciones y laboratorios;
este paquete no incluye todavía aplicaciones ni scripts ejecutables.
