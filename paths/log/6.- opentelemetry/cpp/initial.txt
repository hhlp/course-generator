OPENTELEMETRY CON C++ — DE 0 A EXPERTO EN PROFUNDIDAD

Especialización independiente · idioma español · revisión 2026-10-22
Prerrequisitos: fundamentos del curso general de OpenTelemetry y C++ básico.
El bloque 1 es un puente técnico, no un curso completo de C++.
Contenido de este paquete: currículo y configuración para generar lecciones.
Los fuentes y scripts de los laboratorios se producirán al desarrollar cada lección;
este ZIP no contiene una implementación ejecutable del laboratorio.
Orden: bloques 0–28, 30–33; bloque 29 opcional si se usa Kubernetes.

CONTRATO DE PROFUNDIDAD
Cada lección desarrolla objetivo, mecanismo, uso, límites, ejemplo C++ completo cuando
proceda, errores, comprobación y recapitulación; no basta enumerar opciones.
Cada laboratorio exige versiones fijadas, archivos completos, comandos ejecutables,
resultado esperado, validación de señal, prueba negativa, diagnóstico y limpieza.
Las funciones opcionales requieren evidencia de soporte en la release seleccionada.
